# 娜娜的澳洲起点

一个给两个人一起用的手机网页英语学习原型。设计上借鉴了成熟语言学习产品的核心机制，但没有复制其品牌、角色、文案或专有素材。

## 已经做好的功能

- 手机优先的学习路径
- 两个独立学习者，可随时切换
- XP、连续学习天数、每日最小目标
- 5 颗心机制与错题回炉
- 100 节顺序解锁课程，加入 3 个零基础起步阶段、12 节入门对话课和 15 节澳洲日常情境课
- 从零基础开始：先听懂和模仿高频短句，再替换信息、开口回应，逐步学习语法、听读写和词根
- 普通内容课扩充为 12 个学习环节，约 30 分钟；阶段回顾是短测
- 情境课提供逐句美式语音、中文对照、词汇音标与搭配注释，再用选择和跟读练习巩固
- 每日目标按学习分钟累计；完整内容课完成后记约 30 分钟
- 澳洲场景材料卡包含咖啡菜单、购物清单、尺码牌、小票、公交站牌、GP 预约卡和药品标签
- 课程按“听懂 → 模仿 → 替换 → 自己表达 → 间隔复习”组织；对话逐句播放并附中文，表达卡带释义和用法提示
- 写作题支持直接输入并对照参考答案；不会伪装成自动语法评分
- GPT Live 自由口语提示：按当前课程主题生成可复制的聊天开场，不在网站里固定对话脚本
- 浏览器英文朗读
- 每日一句
- 双人总进度
- 本地进度导入与导出
- PWA，可添加到手机桌面
- 离线缓存基础页面

## 最快打开方式

不要直接双击 HTML 文件，推荐在目录里启动一个本地服务器：

```bash
python -m http.server 8080
```

然后在浏览器打开：

```text
http://localhost:8080
```

如果要在手机使用，最方便的是把整个文件夹部署到 GitHub Pages、Vercel、Netlify 或 Cloudflare Pages。

## 当前双人模式说明

当前原型的数据存储在浏览器 LocalStorage 中。

这意味着：

- 两个人共用同一台手机或同一个浏览器时，可以直接使用。
- 两个人分别使用自己的手机时，数据不会自动同步。
- 页面里提供了 JSON 进度导入与导出，可临时手动同步。

如果希望两台手机实时同步，可以接 Supabase。仓库中已经放了 `supabase-schema.sql` 作为数据库骨架。

## 学习路线与 GPT Live

课程现在共 19 个阶段、100 节（含 14 个阶段回顾）。最前面新增 3 个从零开始的起步阶段，涵盖问候、自我介绍、状态、数字、家人、住处、食物、作息、咖啡店、超市、公交和请求重复等，共 12 节入门对话课。原有 5 题内容课也会扩成约 30 分钟的听读、核心表达、原题巩固和角色回应；15 节澳洲场景课继续提供菜单、购物清单、尺码牌、小票、公交站牌、GP 预约卡和药品标签等材料。学习过程按“先听懂 → 跟读模仿 → 替换信息 → 自己回应 → 阶段复习”递进，借鉴儿童语言学习的重复和情景输入方式，例句与场景面向成人日常生活。课程从 A0 起步，目标是建立雅思 4.5 所需的基础能力，不等于完整雅思课程，也不承诺考试分数；写作参考答案需要自己对照，尚无自动语法评分。浏览器可朗读英文，但目前不自动识别或评分用户语音。

需要自由口语时，点“GPT Live 自由口语”，复制当次课程主题的提示，再在 ChatGPT 中开启 Live 语音。GPT 可根据回答自然追问；网站课程继续负责词汇、语法、听读和复习。

## 设计说明

本项目使用自己的名称、图标和界面视觉。核心只借鉴语言学习产品中常见的游戏化设计原则，例如学习路径、连续天数、经验值、低门槛小课、错题复习和即时反馈。
