# 娜娜的澳洲起点

一个给两个人一起用的手机网页英语学习原型。设计上借鉴了成熟语言学习产品的核心机制，但没有复制其品牌、角色、文案或专有素材。

## 已经做好的功能

- 手机优先的学习路径
- 两个独立学习者，可随时切换
- XP、连续学习天数、每日最小目标
- 5 颗心机制与错题回炉
- 85 节顺序解锁课程，包含阶段回顾和 15 节完整日常情境对话课
- 情境课提供逐句美式语音、中文对照、词汇音标与搭配注释，再用选择和跟读练习巩固
- 每日目标改为按学习分钟累计：基础小课约 5 分钟，完整情境对话课约 30 分钟
- 澳洲场景材料卡包含咖啡菜单、购物清单、尺码牌、小票、公交站牌、GP 预约卡和药品标签
- 基础课以约 5 分钟的小节循序学习日常表达、基础语法、听力、阅读、短写作和词根词缀；新情境对话课每节 12 个学习环节，约 30 分钟
- 写作题支持直接输入并对照参考答案；不会伪装成自动语法评分
- GPT Live 自由口语提示：按当前课程主题生成可复制的聊天开场，不在网站里固定对话脚本
- 浏览器英文朗读
- 每日一句
- 双人总进度
- 本地进度导入与导出
- PWA，可添加到手机桌面
- 离线缓存基础页面

## 最快打开方式

不要直接双击 HTML 文件，推荐在目录里启动一个本地服务器：

```bash
python -m http.server 8080
```

然后在浏览器打开：

```text
http://localhost:8080
```

如果要在手机使用，最方便的是把整个文件夹部署到 GitHub Pages、Vercel、Netlify 或 Cloudflare Pages。

## 当前双人模式说明

当前原型的数据存储在浏览器 LocalStorage 中。

这意味着：

- 两个人共用同一台手机或同一个浏览器时，可以直接使用。
- 两个人分别使用自己的手机时，数据不会自动同步。
- 页面里提供了 JSON 进度导入与导出，可临时手动同步。

如果希望两台手机实时同步，可以接 Supabase。仓库中已经放了 `supabase-schema.sql` 作为数据库骨架。

## 学习路线与 GPT Live

课程共 16 个阶段、85 节（含 11 个阶段回顾）。基础课程仍以 5 分钟左右的小节循序建立语法和读写能力；阶段 14 至 16 新增 15 节约 30 分钟的完整日常情境课，每节含 12 个学习环节：完整对话、逐词讲解、理解题、跟读和 3 轮角色回应。场景包括认识邻居、早上出门、聊天气、邀请朋友、点咖啡、餐馆用餐、超市购物、试衣、结账、公交、打车、诊所预约、药房购药和听不懂时确认信息等。部分课程配有原创澳洲生活场景图片及可读的菜单、购物清单、尺码牌、小票、公交站牌、GP 预约卡和药品标签。对话逐句播放并附中文；关键单词带美式音标、含义和实用搭配。每日学习目标按分钟累计：完成一节基础课记约 5 分钟，完成一节完整情境课记约 30 分钟。课程也包含过去与未来表达、听力、阅读、短写作、词根词缀和综合检查。当前内容是面向初学者的雅思 4.5 基础准备路线，不等于完整雅思课程，也不承诺考试分数；写作参考答案需要自己对照，尚无自动语法评分。

需要自由口语时，点“GPT Live 自由口语”，复制当次课程主题的提示，再在 ChatGPT 中开启 Live 语音。GPT 可根据回答自然追问；网站课程继续负责词汇、语法、听读和复习。

## 设计说明

本项目使用自己的名称、图标和界面视觉。核心只借鉴语言学习产品中常见的游戏化设计原则，例如学习路径、连续天数、经验值、低门槛小课、错题复习和即时反馈。
